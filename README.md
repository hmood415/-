## ⚙️ الإعدادات

### إعداد Supabase (اختياري)

لتفعيل حفظ البيانات في قاعدة البيانات:

1. اذهب إلى [supabase.com](https://supabase.com)
2. أنشئ مشروعاً جديداً
3. انسخ **Project URL** و **anon key**
4. في `index.html`، استبدل:
   ```javascript
   const SUPABASE_URL  = "your-project-url";
   const SUPABASE_ANON = "your-anon-key";
   ```
5. شغّل SQL setup من ملف `supabase_setup.sql`:
   - افتح SQL Editor في Supabase
   - انسخ والصق محتوى `supabase_setup.sql`
   - اضغط Run

### إعداد واتساب

تعديل رقم الواتساب في `index.html`:
```javascript
const WA_NUM = "966542378596"; // غيّر هذا برقمك
```

## 💾 البيانات والـ API

### جداول قاعدة البيانات

#### جدول `clients`
```sql
id:        UUID (مفتاح أساسي)
name:      TEXT (اسم العميل)
phone:     TEXT (رقم الجوال - فريد)
created_at: TIMESTAMP (وقت الإنشاء)
```

#### جدول `bookings`
```sql
id:              UUID (مفتاح أساسي)
client_phone:    TEXT (رقم الجوال)
client_name:     TEXT (اسم العميل)
service_title:   TEXT (اسم الخدمة)
provider_name:   TEXT (اسم المختص)
provider_spec:   TEXT (تخصص المختص)
booking_date:    TEXT (تاريخ الجلسة)
booking_time:    TEXT (وقت الجلسة)
duration_label:  TEXT (مدة الجلسة)
duration_id:     TEXT (معرف المدة)
cost:            INTEGER (التكلفة بالريال)
status:          TEXT (حالة الحجز)
created_at:      TIMESTAMP (وقت الإنشاء)
```
